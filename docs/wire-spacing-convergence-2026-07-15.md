# 도선 간격(d) 수렴 스윕 — 차단 κ 측정 정확도 근거자료

작성: 2026-07-15. 목적: 고차 모드 시뮬레이션에서 자동 도선 간격 `dAuto`를
"왜 이 값인가"를 실측으로 정당화한다. 논문의 도선 간격 조건 근거로도 사용 가능.

## 배경

- 벽은 두 줄 도체 도선 배열(y=±a/2), 내부 장 = 입사파(내부 선원) + 산란파(MoM).
- 차단 모드는 진행축 z를 따라 `e^{−κz}`로 감쇠한다. 측정 κ를 이론 κ=√((nπ/a)²−k²)와 대조.
- 측정 창(엔진 core.js `kappaFitWindow`의 검증된 규칙): `[0.15L, min(0.7L, 0.15L + 2.5/κ)]`
  — 끝단을 2.5 감쇠길이에서 잘라 **누설 바닥(floor) 도달 전**에 피팅. (이 캡을 빼면 κ가
  계통적으로 낮게 나옴 — core.js 주석의 "82.8% 사례"와 본 실험의 83%가 일치.)
- 고정값: a=60, L=300, xLeft=xRight=110, Ny=220, y0pix=110, aw=0.8, 내부 선원 z0=36(=0.12L).

## 해석

핵심 물리량은 **감쇠길이 1/κ 대비 벽/창 분해능**이다.

1. **n1 (1/κ=34.6셀, 잘 분해됨):** d가 촘촘할수록 단조 개선(0.100→73%, 0.050→95%, 0.040→99%).
   벽이 성기면 유효 벽폭이 살짝 넓어져 κ가 낮게 나온다. → 촘촘한 d 선호.
2. **②n3 (1/κ=7.1셀, 민감):** 뚜렷한 스위트스팟 — d/λ=0.055에서 101%, 그보다 촘촘하면
   과대(0.040→134%), 성기면 과소(0.080→70%). 단조.
3. **③n3 (1/κ=11.5셀, 안정):** 모든 d에서 101–109%로 **매우 안정하나 계통적 +5~9% 편향**.
   (이산 sin-투영/이산 k_c에서 오는 작은 systematic으로 추정. 별도 조사 대상.)
4. **①n3 (1/κ=6.6셀, 측정 불가):** 감쇠길이가 벽 간격·선원 근접장 규모와 맞먹어
   **어떤 d에서도 95–105%에 들지 못함**(−41%~179%, 비단조). 창 시작을 감쇠기반(z0+2/κ)으로
   바꿔도 개선 안 됨(sweep2 확인). → **원리적 측정 한계 → 정직한 라벨 대상.**

### 단일 dAuto=c·λ의 한계
- 어떤 단일 c도 **모든** 차단 모드를 엄격한 95–105%에 넣지 못한다:
  ③n3는 항상 ≥105%(고유 편향), ①n3는 원리적으로 불가.
- 측정 가능한 잘 분해된 모드(①n1, ②n3, ③n3)만 보면, c≈0.050–0.055가 최적:
  - c=0.055: ①n1 94% / ②n3 101% / ③n3 108% (모두 ±8% 이내).
  - c=0.050: ①n1 95% / ②n3 111% / ③n3 109%.
- 참고: **엔진 core.js 자체 판정 기준은 ±15%**(85–115% PASS, core.js:267). 이 기준으로는
  c≈0.055에서 측정 가능한 세 모드 전부 통과, d/λ≤~0.06까지 여유.

## 권고 (다음 세션에서 사용자 확인 후 확정)

- **dAuto = 0.055·λ** 채택(벽무결성 d≤0.1λ 만족, 측정 가능한 모드 ±8% 이내, 가장 큰=가장 가벼운
  축에 가까움). 필요 시 `clamp`로 하한(계산보호)·상한(0.1λ) 유지.
- **판정 밴드**: 엄격 ±5%는 물리적으로 불가 → **±10~15%**(엔진과 정합)로 채택.
- **라벨**: 1/κ가 벽 간격·창에 비해 너무 작아 깨끗한 기울기를 얻을 수 없는 모드(예 ①n3)만
  "측정 불가(수치 바닥/분해능 한계)". 그 외 모드는 반드시 측정/이론 숫자 표기.
- **벽 무결성 vs κ 민감도**: |T|는 d/λ=0.08에서도 통과였으나 κ는 어긋났다. 즉 **근접차단 κ 정확도가
  |T|보다 엄격한 기준**이다. |T| 경고 임계는 유지하되, "모드 분해 신뢰 = d/λ≲0.06(κ 기준)"임을 명시.
